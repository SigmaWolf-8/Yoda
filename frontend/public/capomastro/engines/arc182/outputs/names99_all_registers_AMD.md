## Which Scripts Actually Have a Decimal (the honest constraint)
Additive letter-value gematria exists only in the **Semitic abjads and Greek**. These give a true native decimal:

| Script | Native gematria? | Value system |
|--------|------------------|--------------|
| Phoenician | **Yes** | 22-letter Semitic | alef=1 … taw=400 |
| Aramaic (Syriac) | **Yes** | identical 22-letter Semitic values |
| Arabic Abjad | **Yes** | 28-letter | alif=1 … ghayn=1000 |
| Kufic | **Yes** (= Arabic) | Kufic is a calligraphic style of Arabic script |
| Greek (Milesian) | **Yes** | α=1 … ω=800, ϡ=900 |
| Sanskrit (Devanagari) | **No additive gematria** | Kaṭapayādi is positional digit-encoding, not additive |
| Musnad (Old South Arabian) | **No** | ASA used separate numeral signs, not letter-values |
| Avestan | **No** | liturgical phonetic script, no numeral tradition |
| Pahlavi | **No** | Aramaic-derived; used arameograms + separate numeral signs |

For the four without native gematria, the only honest decimal is the **Milesian rendering** of their phonetic content | the comparative register that lets all nine be set side by side. That rendering is marked (M).
