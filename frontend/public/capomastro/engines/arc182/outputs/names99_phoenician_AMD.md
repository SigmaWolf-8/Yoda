## Method | The Parent-Daughter Rendering
Phoenician is the **parent** of the Greek alphabet. Each of the 22 Phoenician letters is rendered to the exact Greek letter it historically became, preserving the numeral value | alef→α(1), bet→β(2), gimel→γ(3), … waw→ϛ(6, digamma), … qof→ϙ(90, koppa), … tsade→ϡ(900, sampi), … taw→τ(300). This is not romanization | it is the true alphabetic descent, letter for letter, word for word. Because Phoenician, Hebrew, Greek, and Arabic-Abjad all inherit the one Semitic letter-order and its values, the Phoenician-Greek value **equals** the classical gematria value | a genuine equivalence, computed independently.
